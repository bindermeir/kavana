# מחקר לוח השנה: מהטקסטים בלבד

## מטרה
לבדוק איזה לוח שנה (או לוחות) עולה מתוך הטקסטים עצמם: התנ"ך ומגילות קומראן, עם ספר חנוך וספר היובלים בנוסחם המלא. הבדיקה לא מניחה מראש אף לוח קיים. התוצאה האפשרית יכולה להיות לוח אחד, כמה לוחות, לוח חדש, או המסקנה שהטקסטים אינם מכריעים.

## עקרונות
1. **רק טקסטים ראשוניים.** אין פרשנים, אין תלמוד ואין ספרות מחקר. החריג היחיד הוא תיארוך הספרים, ששאול מהמחקר המקובל (ראה למטה), ומשמש רק כדי לקבוע את סדר השלבים.
2. **מחקר מדורג לפי זמן הכתיבה.** כל שלב מוסיף שכבת טקסטים שנכתבה (לפי המחקר) מאוחר יותר. בכל שלב נבנה לוח מעודכן. כל הגרסאות הקודמות נשמרות.
3. **הפרדה בין מנהל המחקר לחוקרים.** מנהל המחקר מכין את החומרים ואת הסביבה. החוקרים (סוכנים) עובדים בתוך סביבה סגורה, בלי רשת ובלי הרצת קוד, ורואים רק את הטקסטים של השלב שלהם. הם לא מקבלים את דעת המנהל.
4. **אסטרונומיה בכל שלב.** טבלאות של מה שנראה בשמי ירושלים (מולדות, ראיית הסהר, ירח מלא, שוויונים והיפוכים, זריחה ושקיעה) זמינות מהשלב הראשון. זה מה שכותבי הטקסטים ראו בעיניים.
5. **כל טענה עם מראה מקום.** טענה בלי ציטוט נפסלת.

הערות:
- **חלוקת התורה למקורות** היא לפי השערת התעודות הקלאסית. הפירוט, פסוק אחר פסוק, נמצא ב-`methodology/pentateuch_sources.tsv`. פסוקים מעורבים חולקו באתנח (קירוב).
- **תיארוך חלק מהספרים שנוי במחלוקת**, למשל תהלים (מזמורים מתקופות שונות), יואל, ומגילת המקדש. הבחירה כאן היא באמצע טווח המחלוקת.
- **שמות יב:כא-כז ושמות יג:ג-טז** שויכו ל-JE כמו בחלוקה הקלאסית. חוקרים אחרים רואים בהם קטעים קרובים לספר דברים.

- **Charles:** הוסרו חישובי השנים שלו (Anno Mundi), הפניות, והערות המתרגם.

## אסטרונומיה
`tools/build/astro_tables.py` מחשב לירושלים, 1000 לפנה"ס עד 70 לספירה, עם PyEphem. ראיית הסהר מחושבת לפי מבחן Yallop. החישוב נבדק מול ראיות מודרניות (מרץ 2024, אפריל 2023) ותאם.

## מבנה התיקיות
- `methodology/`: מסמכי שיטה (תיארוך, חלוקת מקורות).
- `tools/build/`: סקריפטים לבניית הסביבה (מנהל המחקר בלבד).
- `sandbox/stage-NN/`: סביבת עבודה סגורה לכל שלב. הקורפוס והאסטרונומיה נבנים מחדש בסקריפט ואינם נשמרים ב-git. `output/` נשמר.
- `results/`: הלוח של כל שלב (v1, v2, ...) ויומן השינויים.

## בנייה מחדש
```
git clone --depth 1 https://github.com/openscriptures/morphhb.git _downloads/morphhb
git clone --depth 1 https://github.com/ETCBC/dss.git _downloads/dss
git clone --depth 1 https://github.com/scrollmapper/bible_databases_deuterocanonical.git _downloads/bible_databases_deuterocanonical
pip install text-fabric ephem
python3 -I tools/build/export_dss.py _downloads/dss/tf/2.0.5 _work/dss_txt
unshare -n python3 -I tools/build/astro_tables.py _work/astronomy
unshare -n python3 -I tools/build/eclipses.py _work/astronomy
python3 -I tools/build/build_stage.py $PWD <N>
```
