# תיקיית שלב מחקר

- `corpus/` - הטקסטים של השלב הזה בלבד. `MANIFEST.tsv` מפרט כל יחידה ואת השכבה שלה. מספר שכבה נמוך = נכתב (לפי המחקר) מוקדם יותר.
  - `layer-N/*.txt` - טקסט עיצורי (הנוסח הראשי).
  - `layer-N/pointed/` - אותו טקסט עם ניקוד המסורה (קריאה מאוחרת; לעיון משני).
  - `layer-N/qumran/` - מגילות קומראן (אם יש בשלב).
- `astronomy/` - מה שנראה בשמי ירושלים. ראה astronomy/README.md.
- `output/` - כאן כותבים את התוצרים.
